Windows

Instalador `.exe`. Roda em qualquer Windows 64-bit recente.

  1. Baixe o arquivo abaixo (~3 MB)
  2. Dê dois cliques pra abrir
  3. Se aparecer aviso azul "Unknown publisher", clique em Mais informações → Executar mesmo assim

macOS

Apple Silicon · M1, M2, M3, M4

Disk image `.dmg`. Pra Macs com chip da Apple (não funciona em Macs Intel).

  1. Baixe o arquivo abaixo (~9 MB)
  2. Abra o `.dmg` e arraste o Fotopia pra Applications
  3. Primeira abertura: botão direito no app → Abrir → Abrir (contorna o Gatekeeper)
Baixar pra Mac
